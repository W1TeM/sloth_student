## Пример кода на Python
Ниже представлен небольшой скрипт, написанный в рамках знакомства с языком Python. Функция проверяет, является ли введенное слово палиндромом.

```python
def is_palindrome(word):
    # Приводим слово к нижнему регистру и убираем пробелы
    clean_word = str(word).lower().replace(" ", "")
    return clean_word == clean_word[::-1]

# Проверка работы функции
test_word = "А роза упала на лапу Азора"
if is_palindrome(test_word):
    print("Строка является палиндромом!")
else:
    print("Это не палиндром.")```
